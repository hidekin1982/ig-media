印刷代は1冊530円。A4もB5も「大判」に入ります

分かれ目は、紙の本にだけある原価、印刷代です。

KDPのヘルプでは、印刷代は「固定費＋ページ数×1ページの単価」で決まり、黒インクで24〜110ページの本なら、ページ数に関係なく固定費だけで済みます。

Amazon.co.jpでは、こうです。

  • 標準判：1冊422円
  • 大判：1冊530円
  • 大判とは、幅155.5mm、または高さ228.6mmを超えるもの

A4（21.0×29.7cm）もB5（18.2×25.7cm）も、この線を超えます。どちらも530円。

A5（14.8×21.0cm）なら標準判で422円です。

24ページでも110ページでも同じ。110ページを超えると「206円＋ページ数×3円」（大判）に変わります。

用紙を「砕木パルプ紙」にすると大判の24〜112ページで513.80円と少し下がるものの、紙が白やクリームの用紙（74〜90g/m²）より薄い60g/m²になるので、色鉛筆で塗ったときにどう見えるかは、私はまだ確かめていません。

迷ったら、530円で計算します。

999円と1,000円で率が変わる。1,000円の本で残るのは70円

紙の本の取り分は、こう決まります。

（率 × 希望小売価格）− 印刷代 ＝ ロイヤリティ

Amazon.co.jpの率は、希望小売価格が999円以下なら50%、1,000円以上なら60%です。

白黒・24〜110ページで引き算すると、こうなりました。

  • 999円 … 率: 50% ／ A4・B5（印刷代530円）: −30.5円 ／ A5（印刷代422円）: 77.5円
  • 1,000円 … 率: 60% ／ A4・B5（印刷代530円）: 70円 ／ A5（印刷代422円）: 178円
  • 1,200円 … 率: 60% ／ A4・B5（印刷代530円）: 190円 ／ A5（印刷代422円）: 298円
  • 1,500円 … 率: 60% ／ A4・B5（印刷代530円）: 370円 ／ A5（印刷代422円）: 478円
  • 2,000円 … 率: 60% ／ A4・B5（印刷代530円）: 670円 ／ A5（印刷代422円）: 778円

999円はマイナスです。

KDPには、印刷代を引いても必ず取り分が残るように「最低希望小売価格」があって、それを下回る金額は入力できません。式は「印刷代÷率」。

A4で計算すると、50%なら1,060円、60%なら883.3円になり、50%の帯は999円まで、60%の帯は1,000円からなので、計算上はA4・B5の塗り絵を1,000円より下で出すことはできません。

ただ、私は価格の画面そのものは見ていません。ここは「計算上」です。

1,000円は税抜きの価格です。Amazonの表示には消費税10%が足されて、1,100円になります。

日本向けの価格設定のヘルプに、紙の本は税抜きで希望小売価格を決めると消費税が自動で追加される、とありました。最低希望小売価格も税抜きで、ロイヤリティは消費税を引いたあとの価格から計算します。

  • B5（18.2×25.7cm） … 印刷代: 530円 ／ 必要なピクセル: 2,150×3,036px

手元の画像が何DPIになるかは、割り算1回です。

実効DPI ＝ 横のピクセル ÷（本の幅mm ÷ 25.4）

横1,024pxの画像をA4の幅いっぱいに置くと約124DPI、B5で約143、A5でも約176。

足りません。

指示文を通したとき、AIは頼んでいないのに、10本すべての指示文の最後に「A4縦」と書き足していました。でも、そう書いても画像生成AIが出すピクセル数は決まりません。

フォルダの画像をまとめて調べるために、私はこれを作りました（PythonとPillowが要ります）。

# 使い方：python dpi_check.py 画像のフォルダ
import sys, pathlib
from PIL import Image

HABA_MM = {"A4": 210, "B5": 182, "A5": 148}

for p in sorted(pathlib.Path(sys.argv[1]).iterdir()):
    if p.suffix.lower() not in (".png", ".jpg", ".jpeg"):
        continue
    w, h = Image.open(p).size
    kekka = [f"{k} {w / (mm / 25.4):.0f}DPI" for k, mm in HABA_MM.items()]
    chui = "" if w / (210 / 25.4) >= 300 else "  ← A4では300DPIに届かない"
    print(f"{p.name}  {w}x{h}px | " + " / ".join(kekka) + chui)

大きさ違いのダミー画像12枚で動かして、1,024pxの画像に印が付くのを確かめました。

グレーにも決まりがあります。グレーの背景を黒インクで刷るなら、濃さを10%以上にすることがすすめられていました。

塗り絵は無料のISBNで出せます。ISBNなしにできるのは「コンテンツが少ない本」だけ

冒頭の取り違えが、一番効いてくるのがここです。

ペーパーバックにはISBN（本の番号）が要り、KDPの無料のISBNはペーパーバックとハードカバーで使えます。

ただし「コンテンツが少ない本」は無料のISBNの対象外で、その代わり「ISBNなしで出版する」を選べます。

塗り絵をそちらで出したと仮定すると、次の制限がかかります。

  • ISBNなしだと、「サンプルを読む」（試し読み）と裏表紙のサムネイルに対応しない
  • シリーズは作れない（ISBNの選び方に関係なく）
  • 外部流通は使えない（同じく）
  • 出版後にISBNの選び方は変えられない（変えるなら出版を止めて出し直す）

塗り絵こそ、中身を見せたい本です。

これは痛い。

ノートや日記帳の人は逆で、カテゴリーで「コンテンツが少ない」にチェックを入れないと本は拒否される、と書かれています。塗り絵にこのチェックを入れたらどうなるかは、ヘルプにありませんでした（未確認）。

出版したあとは、インクを白黒からカラーへ、またはその逆へは変えられません。

バーコードの専用ページには、自分で作る場合の推奨サイズが同じ50.8×30.5mmとありました。バーコードの位置に絵や文字がある表紙は却下される、とも。

自動で置かれる枠の大きさそのものは、書いていません。そこは未確認です。

右下は空ける。

表紙は、表・背・裏がつながった1枚の画像で作ります。

  • 四方すべてに3.2mmの裁ち落とし
  • 切れてはいけない文字や絵は、外の縁から6.4mm以上内側

  • 背表紙に文字を入れられるのは、79ページを超える本だけ

A4・24ページなら、背表紙は約1.37mm。表紙全体は幅427.77mm×高さ303.4mmで、300DPIなら5,053×3,584pxです。

出版ボタンを押してから、手元にお金が入るまでの時間です。

  • 審査：通常3〜10営業日。審査中は本を変更できない
  • 購入できるようになってから、検索に出るまで：最大72時間

日本の銀行口座で受け取る直接振り込みには、通常、最低支払い金額の設定がありません（KDPの支払い方法のヘルプ）。「通常」とあるので、ゼロとは言い切りません。

はっきりしているのは出ていく側だけで、A4の白黒なら印刷代は1冊530円、1,000円で出せば残るのは70円。
