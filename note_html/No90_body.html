デザインを作った指示文は、これで全部です

私の場合は、AIに頼んで画像を作るスクリプトを書いてもらいました。同じものを頼むなら、この指示で足ります。

PythonとPillowで、SUZURIに出す文字デザインの画像を作るスクリプトを書いてください。

条件
・画像サイズは横2520px × 縦2992px、背景は透明のPNG
・文字は3行。1行目は小さめ、2行目はいちばん大きく、3行目は中くらい
・2行目だけオレンジ色（#D97757）、それ以外は黒（#181412）
・フォントは Noto Sans JP（Google Fonts・SIL Open Font License）だけを使う
・2行目と3行目は Black、1行目は Bold の太さにする
・左右に180pxの余白を取り、はみ出す行は自動で文字を小さくする
・全体を上下左右の中央に置く
・黒文字版と白文字版の2枚を書き出す

文字
1行目：本日の業務は
2行目：AIが
3行目：担当します

文字の3行を差し替えれば、別の言葉でも同じ形で作れます。私も2つ目のデザインは、ここを「定時で帰るために／AIを／使っています」に変えただけでした。

画像ができてからは、SUZURIの出品画面を4つ進めるだけでした。画像を1枚上げると、Tシャツやマグカップに文字を乗せた見本が一覧で並びます。私はその中から7種類を選び、説明文を2行書いて、最後に確認の画面で「販売する」を押しました。

引っかかったのは、フォントを商品に使ってよいかでした

画像を作る前に、手元のパソコンに入っているフォントを見直しました。

Windowsには游ゴシックやメイリオなど、きれいな日本語フォントが最初から入っています。これを使えば早いと思いました。

でも、グッズにして売ってよいかを確かめようとしたところで手が止まりました。パソコンで文書を作るのに使えることと、印刷した商品を売ってよいことは、同じ条件とは限りません。

確かめきれないものは使わない、と決めました。

選んだのは Noto Sans JP です。Google Fonts で無料配布されていて、SIL Open Font License（OFL）というライセンスが付いています。OFLはフォントを使った作品の販売を認めていて、グッズの印刷もその範囲に入ります。

私のパソコンには入っていました。無ければ Google Fonts から無料で入手できます。

  • 使わない：確かめていない付属フォント（游ゴシック、HG系など）
  • 迷ったら：配布ページのライセンス欄を読んでから決める

サイズはTシャツの2520×2992pxに合わせるだけでした

SUZURIの公式ページには、アイテムごとの推奨入稿サイズが並んでいます。スタンダードTシャツは横2520 × 縦2992pxです。

最初は、商品ごとに画像を作り分けるものだと思っていました。マグカップは横長、ステッカーは正方形です。

実際は違いました。Tシャツ用の1枚を上げると、SUZURIがほかの商品にも自動で当てはめて、完成見本を並べてくれます。

これには少し驚きました。1枚の画像から、Tシャツもパーカーもマグカップも同時に見本ができあがります。

  • 画像は1枚でよい（Tシャツの推奨サイズで作る）
  • 形式はPNGかJPG、15MB以下（アップロード画面の表示）
  • 背景は透明にしておく（白い商品にも色付きの商品にも乗る）

今回の画像は1枚あたり約120KBでした。15MBの上限にはまったく届きません。文字だけのデザインは軽いです。

黒文字1枚で、白い商品のほとんどが埋まります

スクリプトは黒文字版と白文字版の2枚を書き出します。どちらを上げるか迷いましたが、今回は黒文字だけにしました。

理由は単純で、SUZURIの見本の多くが白い商品だったからです。Tシャツ、マグカップ、ステッカー、トートバッグ。黒文字ならそのまま読めます。

白文字は黒いTシャツ向けです。白い商品に乗せると文字が消えてしまいます。

  • 黒文字：白・淡い色の商品向け。対応できる商品がいちばん多い
  • 白文字：黒・濃い色の商品向け。別の画像として追加で出す

両方出したいなら、同じデザインを2回出品すればよいだけです。最初の1点は黒文字で十分でした。

オレンジ色の部分は、白い商品でも黒い商品でも読める色にしてあります。強調したい1語だけに色を付けると、遠くからでも目に入ります。

出品の画面は4つだけでした

SUZURIの出品は、画面の上に4つの段階が表示されます。

1. アップロード（画像を選ぶ）

2. アイテム選択（どの商品にするか）

3. 名前・価格決め（商品名、説明、取り分）

4. 販売

アカウントを作ってログインしたあとは、この4つを順に進めるだけです。私はこの画面を2回通して、2デザインを出しました。

入口は、ログイン後のメニューにある「グッズ（販売用）」です。トップページの「ショップで販売する」からも同じ画面に行けます。

画像を選ぶと、すぐに2つ目の段階に切り替わります。アップロードの完了を待つ時間は、ほとんどありませんでした。

  • 画像を選んだ時点で、商品の見本が一覧で出る
  • 途中の段階に戻ることもできる
  • 最後に確認の画面が1つ出る

見本を1つずつ見ていくと、明らかにおかしいものが1つありました。卓上カレンダーです。

カレンダーの絵の面は、画像の中央を大きく切り取って使う形でした。3行の文字のうち「AIが」だけが大きく写り、それも端が欠けていました。前後の言葉は見えません。

これでは何の一言なのか伝わりません。外しました。

出す前に見本を一つずつ見ておいてよかったと思います。一覧で眺めただけだと、小さくて気づきにくい崩れ方でした。

  • 文字が切れている商品は選ばない
  • 縦長・横長の極端な商品ほど崩れやすい

逆に言えば、崩れていなければそのまま出せます。7種類のうち、直しが必要なものは1つもありませんでした。

取り分は初期値の300円のまま出しました

3つ目の段階で、商品名・説明・取り分を入れます。取り分はSUZURIではトリブンと呼ばれていて、最初から300円が入っていました。

今回はそのまま300円で出しています。

買う人が払う金額は、原価と取り分だけではありません。公式ヘルプによると、取り分の10%が手数料として原価に足されます。

入ってくるのは、どれも1点につき300円。手数料は買う人の側に乗るので、自分の取り分は減りません。

取り分の決め方は前回の記事に詳しく書きました。最初の1点は、迷わず初期値で出してしまってよいと思います。値段はあとから変えられます。

私が使ったスクリプトの全文

私が使ったスクリプトを、1デザイン分に短く整理したものです。PythonとPillowが入っていれば、そのまま動きます。

from PIL import Image, ImageDraw, ImageFont

FONT = r"C:\Windows\Fonts\NotoSansJP-VF.ttf"  # Noto Sans JP（OFL）
W, H = 2520, 2992
ACCENT = (217, 119, 87, 255)

LINES = [
    ("本日の業務は", 250, "Bold", False),
    ("AIが", 620, "Black", True),
    ("担当します", 400, "Black", False),
]

def font(size, weight):
    f = ImageFont.truetype(FONT, size)
    f.set_variation_by_name(weight)
    return f

def render(ink):
    img = Image.new("RGBA", (W, H), (0, 0, 0, 0))
    d = ImageDraw.Draw(img)
    rows = []
    for text, size, weight, accent in LINES:
        f = font(size, weight)
        while d.textbbox((0, 0), text, font=f)[2] > W - 360:
            size -= 10
            f = font(size, weight)
        box = d.textbbox((0, 0), text, font=f)
        rows.append((text, f, box, ACCENT if accent else ink))
    gap = 70
    total = sum(b[3] - b[1] for _, _, b, _ in rows) + gap * (len(rows) - 1)
    y = (H - total) // 2
    for text, f, box, col in rows:
        w = box[2] - box[0]
        d.text(((W - w) // 2 - box[0], y - box[1]), text, font=f, fill=col)
        y += (box[3] - box[1]) + gap
    return img

render((24, 20, 18, 255)).save("design_black.png")
render((250, 247, 243, 255)).save("design_white.png")
print("OK")

フォントの場所は私のパソコンの例です。別の場所に入れた場合は、FONT = の行を書き換えてください。

文字を変えたいときは LINES の3行だけを直します。数字は文字の大きさです。長い言葉は自動で縮むので、まずはそのまま試してください。

  • 変えるのは LINES の文字だけ
  • 色を変えるなら ACCENT の数字
  • 出てきた2枚のうち、黒文字版をSUZURIに上げる

出したあとに確かめたこと

出品が終わったあと、ショップのページで2つのことを確かめました。

1つ目は商品数です。2デザイン×7種類で、14商品が並んでいることを数えました。選び忘れや二重の出品があると、ここで気づけます。

2つ目は、見本の文字が切れていないかです。一覧の小さな画像でも、切れていればすぐ分かります。今回は問題ありませんでした。

売上は、この記事を書いている時点で0円です。出した当日なので当然ですが、それもそのまま書いておきます。

  • 商品数を数える
  • 見本の崩れをもう一度見る
  • 売上は管理画面の「売れたもの」で確かめられる

売れたかどうかは、時間がたってから別の記録にまとめるつもりです。
