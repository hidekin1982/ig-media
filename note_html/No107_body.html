先に書いておくと、私はKindleで本を出したことがない

SUZURIとLINEスタンプには、AIで作ったものを出したことがあります。Kindleは、ヘルプを読んだだけ。

この記事の数字は、2026年11月7日の朝にKDPのヘルプ8ページを読み直して確かめました。10月31日に一度読んだページで、中身は変わっていませんでした。

最初に読んだ10月31日に、自分の古い記事の誤りに気づきました。

8月に、AIでKindle本を出す手順を書いた有料記事があります。

その中の「70%を選べる値段」が、今の公式の表と合っていませんでした。11月6日に、公式の数字に直しています。

AI生成かAIアシストかの線引き × 70%の値段の幅 × KDPセレクトの条件 ＝ 出す前に決めることが3つで済む

「AI生成」と「AIアシスト」。申告が要るのは前者だけ

KDPのコンテンツガイドラインには「人工知能 (AI) コンテンツ」という項目があります。

新しい本を出すとき、または出した本を編集して出し直すとき、AIで生成した中身（文章・画像・翻訳）があれば、KDPに知らせる必要があります。一方で、AIアシストの中身は知らせなくてよい、と書かれています。

ヘルプの定義を、表にするとこうなります。

  • AIで文章・画像・翻訳を作った … 扱い: AI生成 ／ 申告: 要る
  • AIで作ったあと、自分で大きく直した … 扱い: AI生成のまま ／ 申告: 要る
  • 表紙・本文の画像をAIで作った … 扱い: AI生成 ／ 申告: 要る
  • 自分で作ったものを、AIで直した・チェックした … 扱い: AIアシスト ／ 申告: 要らない
  • AIでアイデアを出し、文章や絵は自分で作った … 扱い: AIアシスト ／ 申告: 要らない

分かれ目は「中身を最初に作ったのは誰か」です。

料理に置きかえると分かりやすいです。

買ってきたお惣菜を、自分の皿に盛り付け直しても「手作り」とは言いませんよね。自分で作った料理に、家族が味見をして塩を足したなら、それは自分の料理です。

AIで作ってから大きく直しても、「AI生成」のまま

ここは、読み落としやすい一文です。

ヘルプには、AIで実際の中身を作った場合は「後で大幅な編集を行ったとしても」AI生成と見なす、とあります。

  • AIに下書きを書かせて、全部の段落を自分の言葉に書き直した → AI生成
  • AIに出させた絵を、色も形も手で描き直した → AI生成

どれだけ手を入れたかでは、線は動きません。

「ここまで直したから、もう自分の文章だ」と考えたくなる所ですが、KDPの線引きはそうなっていません。迷ったら、最初の一文・最初の一枚を作ったのが誰かを思い出すのが早いです。

表紙・本文の画像も、AIで作ったら申告の対象

申告の対象は文章だけではありません。

ヘルプには、AI生成画像には表紙や本文の画像、アートワークが含まれる、とはっきり書かれています。

  • 文章は全部自分で書いて、表紙だけAIで作った → 表紙について申告が要る
  • 写真集や絵本で、中の絵をAIで作った → 申告が要る

文章を自分で書いた人ほど、表紙のことは見落としやすい所です。

画像を使う本なら、表紙と中の絵を1枚ずつ「誰が作ったか」で確かめておくと安心です。

AIでアイデアを出して自分で書いたなら、申告は要らない

逆に、申告が要らない使い方もはっきり書かれています。

  • 自分で書いた文章を、AIで直した・磨いた・誤字をチェックした
  • AIにアイデアを出してもらい、文章や絵は最後に自分で作った

この2つは「AIアシスト」で、そうした道具の使い方や手順を知らせる必要はない、とあります。

ただし、申告が要らないことと、何でも出せることは別です。

AI生成でもAIアシストでも、すべてのコンテンツガイドラインと、知的所有権のルールを守る必要がある、という一文が続いています。同じページには、JASRACなどが管理している曲の楽譜・歌詞を含む本はKindleストアでは出版できない（日本のみ）、という項目もあります。

印税は35%か70%。本ごとに選ぶ

KDPでは、売れたときの取り分（ロイヤリティ）を35%か70%から選びます。選ぶのは電子書籍ごとです。

  • 35%：消費税などを抜いた希望小売価格の35%
  • 70%：消費税などを抜いた希望小売価格から、配信コストを引いた額の70%

70%を選んでも、70%の対象になる地域の外に住む読者に売れた分は、35%になります。

1冊目は35%、2冊目は70%、のように本ごとに違ってもかまいません。

ただ、70%を選ぶには条件が2つあります。値段の幅と、日本の読者についての条件です。次の2つの見出しで1つずつ書きます。

70%にできる値段は、日本では250〜1,650円（7月7日から上限が広がった）

KDPの「電子書籍の希望小売価格の要件」に、Amazon.co.jpの表があります。

  • 35% … いちばん安い値段: 99円 ／ いちばん高い値段: 20,000円
  • 70% … いちばん安い値段: 250円 ／ いちばん高い値段: 1,650円

この幅の外の値段を付けたいなら、35%を選ぶことになります。

同じページの冒頭に、2026年7月7日から、Amazon.com（アメリカ）の70%の価格帯が2.99〜9.99ドルから2.99〜12.99ドルに広がった、とあります。9.99ドルの上限は2007年から使われていたもので、ほかの国のKDPでも同じような変更が行われた、という書き方です。

日本の以前の上限は、今回読んだページには書かれていませんでした。なので、ここでは今の数字だけを書きます。

私が8月の記事で書いていた幅は、今の表とは違っていました。値段の幅は、出す日にもう一度表を見てください。

日本の読者への販売で70%にするには、KDPセレクトへの登録が要る

値段の表のすぐ下に、注意書きがあります。

ブラジル、日本、メキシコ、インドの読者への販売で70%を選ぶには、電子書籍をKDPセレクトに登録する必要がある、という一文です。

KDPセレクトについて、ヘルプに書かれていることをまとめます。

  • 90日間の無料のプログラム
  • 登録すると、その本は自動で読み放題（Kindle+）に入る
  • 登録期間の始まりから3日以内なら、登録を取り消せる。過ぎたら問い合わせ
  • Kindle Countdown Deals（期間限定の値下げ）は、Amazon.co.jpでは使えない

つまり日本の読者に70%で売るなら、読み放題にも入れる、という組み合わせになります。

値段の幅だけ合わせても、セレクトに入れていなければ、日本の読者への売上は70%になりません。

70%は、配信コストを引いた額にかかる

70%は、値段そのものにかかるわけではありません。

ヘルプの式は、消費税などを抜いた希望小売価格から「配信コスト」を引き、その額の70%、という形です。

  • 配信コストは、本のファイルの大きさで変わる
  • ヘルプには、平均の配信コストは1冊につき0.06ドル、とドルで書かれている

日本で1MBあたりいくらかは、今回読んだページには書かれていませんでした。なので金額の例は出しません。

覚えておくのは1つだけで、画像の多い本ほどファイルが大きくなり、引かれる額が増える、ということです。写真集や絵本をAIの絵で作るなら、ここが文章だけの本より効いてきます。

読み放題の分配は「初めて読まれたページ数」。ヘルプの名前は「Kindle+」

KDPのヘルプでは、読み放題の仕組みが「Kindle+」という名前で書かれています。

Kindle+は、登録した本を無制限に読んで聴けるサブスクリプションです。読者はプライム会員でなくても登録できます。

KDPセレクトに入れた本は、自動でここに入ります。

お金の入り方は、売れた冊数ではありません。

  • KDPセレクト グローバル基金というお金の山がある
  • 購読者に読まれた（聴かれた）ページ数の合計のうち、自分の本の割合で分ける
  • 同じ読者が同じページを2回読んでも、払われるのは初めて読まれたときだけ
  • 基金の額は毎月見直され、フォーラムで発表される

もう1つ、セレクトの登録を外したときの一文があります。外すと、ブラジル・日本・インド・メキシコでの売上のロイヤリティは35%に戻る、とあります。

70%とセレクトは、セットで考えるのが早いです。

審査は3〜10営業日。検索に出るまで最大72時間

KDPのヘルプ「出版と審査」によると、本を出版用に出すと審査があります。フォーマットとコンテンツのガイドラインを満たしているかを見るものです。

  • 審査の日数は本の種類で違い、通常は3〜10営業日
  • 権利を確かめる情報が要るときは、もっと長くなることがある
  • 審査中は、本を変更できない
  • 買えるようになってから、検索結果に出るまで最大72時間

審査中に直したくなっても、待つしかありません。

AIの申告も、表紙も、値段も、出す前に決めきっておく。日数の面からも、そう読めます。

お金が入るのは、その月の末日から約60日後

支払いのヘルプには、出版の前に済ませることが2つ書かれています。

  • 振込に使う銀行の情報を入れる
  • 税に関するインタビュー（質問への回答）を済ませる

そのうえで、ある月に最低売上金額を満たすと、その月の末日から約60日後にロイヤリティが支払われます。

  • 月ごとのロイヤリティは、翌月の15日ごろにできる
  • 支払いがある月の20日前後に、支払日の書かれたメールが届く

たとえば11月に売れて最低額を満たしたなら、11月30日から数えて約60日後です。出してすぐお金になる仕組みではない、と分かっておくと焦らずに済みます。

出す前に決める3つと、確かめる7項目

ここまでの話を、出す前に見る表にしました。数字は2026年11月7日に読んだKDPのヘルプによります。

決める3つ

1. AI生成として申告するか（文章・表紙・中の絵を1つずつ）

2. ロイヤリティを35%にするか、70%にするか

3. KDPセレクトに入れるか（日本で70%にするなら入れる）

確かめる7項目

1. 表紙や中の絵に、AIで作った画像が入っていないか

2. 70%にするなら、値段が250〜1,650円に入っているか

3. KDPセレクトの期間は90日。取り消せるのは登録の始まりから3日以内

4. 審査は通常3〜10営業日。審査中は直せない

5. 買えるようになってから、検索に出るまで最大72時間

6. 支払いは、最低額を満たした月の末日から約60日後。銀行情報と税のインタビューは出版の前に

7. JASRACなどが管理している曲の歌詞・楽譜を入れていないか

3つを決めて、7つを確かめる。この表をそのまま写して、出す日の手元に置いておけます。
