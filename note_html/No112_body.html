当てたのは、その日の会話の記録・作業ログ・出した日の記事に書いてあることだけです。書いていなければ「記録に無い」にしました。

記録に無い、というのは「確かめなかった」という意味ではありません。確かめたかどうかが、あとから分からない、という意味です。

当てた10項目

売り場ごとの細かい決まりは外して、どこに出すときでも使える形にしました。右側は、確かめるときに開く場所です。

1. 作るのに使ったAIの利用規約が、売り物にすることを認めているか → そのAIの利用規約の「商用」の項目

2. 出す売り場で、AIの扱いを読んだか → 売り場のヘルプで「AI」と検索

3. 申告の欄がある売り場で、AIで作ったと申告したか → 出品画面と、売り場の規約

4. 他人の作品・キャラ・実在の人・ブランドに似せていないか → 自分がAIに渡した指示文

5. フォント・素材のライセンス → 配布ページのライセンス欄

6. 推奨のサイズ・形式・容量 → 売り場の制作ガイドや推奨サイズのページ

7. 見本を1つずつ大きく見て、切れ・透け・にじみが無いか → 出品画面の見本

8. 同じようなものを大量に出していないか → 自分の出品一覧の数

9. 手数料と振込手数料を引いた残りを、値段を決める前に計算したか → 売り場の手数料と振込のヘルプ

10. 出した日と、確かめたページのURL・更新日を控えたか → 自分のメモ

当て方：記録に書いてあれば「確かめた」、無ければ「記録に無い」

当て方は、次の3つに分けただけです。

  • 記録で確かめられた：記録のどこに書いてあるかを言える
  • 記録に無い：確かめたかもしれないが、書いたものが残っていない
  • 当てはまらない：その項目が、そもそも関係しない

ここでいちばん気をつけたのは、思い出で埋めないことでした。

「たぶん見たはず」は、記録が無ければ確かめようがありません。見ていたとしても、それを他人に見せる方法がありません。

なので、記録の行を指させないものは、全部「記録に無い」にしています。

今朝（2026年11月19日）、ストアの自分のスタンプのページを開くと、「AI情報あり」と表示されていました。

2つとも記録に無かったこと：確かめたページの更新日

LINEスタンプにもSUZURIにも無かったのが、項目10です。

ただ、少しだけ違いがあります。SUZURIのほうは、前の日の記事に公式ヘルプのURLと、読んだ日（9月22日）が残っていました。

でも、そのページがいつ更新されたか、という日付は控えていませんでした。LINEスタンプのほうは、URLも日付も残っていません。

項目9の残る額は、LINEスタンプのほうだけ記録に無いです。

更新日が無いと、あとで規約が変わったとき、自分が読んだのは変わる前か後かが分からなくなります。次の章が、まさにその話です。

LINEの規約の最終更新日は2026年7月1日。出した日との前後は記録から分からない

LINE Creators Marketの利用規約は、最終更新日が2026年7月1日です。AIの表示について書いてある8.13も、この規約の中にあります。

では、私のスタンプはこの日より前に出したのか、後に出したのか。

答えは、分かりません。記録に、申請した日が残っていないからです。

分かるのは、9月2日に作者ページを開いたときには、もうストアに並んでいた、ということだけでした。

もし7月1日より前に出していたら、私は今の8.13を読まずに出したことになります。後なら、読めたはずの条項です。どちらなのかを言えないのが、記録が無いということでした。

  • 規約には最終更新日が書いてある
  • 自分が読んだ日と、出した日を控えておけば、前後はあとからでも分かる
  • 控えていなければ、前後は分からないまま

10項目を自分の出品に当てるときの手順（3つ）

もし、あなたもすでに何かを出しているなら、同じ当て方ができます。

1. 出した日の記録を集める。AIとの会話の履歴、メモ、出品画面のスクリーンショット、その日のSNSの投稿など

2. 10項目に、記録の行を1つずつ当てる。「どの記録の、どこに書いてあるか」を言えるものだけを「確かめられた」にする

3. 記録に無いものは「記録に無い」と書く。思い出で埋めない

これから出す人なら、もっと簡単です。

出す日に、10項目の横に「見たページのURL」と「そのページの更新日」を1行ずつ書いておくだけで、あとから全部確かめられます。

私の場合、SUZURIで7つ確かめられたのは、前の日と出した日に、調べたことと見たことを文章に残していたからでした。何を確かめたかは、書いておかないと残らない。今回わかったのはそれだけです。
